## Projet à découvrir

### GlucoMeals

Mon travail de fin d'études : une application web de gestion alimentaire pour personnes diabétiques, développée avec **Laravel, Livewire et MySQL**. Suggestions de repas adaptées à la glycémie, suivi de la glycémie en temps réel et historique exportable en PDF pour le médecin.
